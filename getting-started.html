✅ Ejercicio para principiantes: preparate para escribir tu primer código!

🧰 Requisitos: Qué necesitas en tu computadora

  • Visual Studio Code (VS Code): Un editor donde escribirás HTML, CSS y JS.
    Descargar VS Code
  • Navegador Web: Chrome, Firefox o Edge para ver tu proyecto.
    Recomendamos Google Chrome por sus herramientas de desarrollo.
  • Git & GitHub: Git para controlar versiones. GitHub para guardarlas online.
    Instalar Git · Crear cuenta GitHub
  • Git & GitHub: Git te ayuda a controlar los cambios. GitHub te permite guardar tu código online.
    Podés elegir entre:
    • 👉 Git + Terminal: Recomendado si querés aprender cómo funciona internamente. Descargar Git
    • 🖥️ GitHub Desktop: Más fácil para empezar. Descargar GitHub Desktop

🧪 ¡Practiquemos! Tu primer proyecto

En tu carpeta de documentos crea una carpeta que diga development-learning y ahí crea una carpeta llamada my-first-website y adentro:

  1. Crea estos 3 archivos: ⓘ
    • index.html
    • style.css
    • script.js
  2. Agregá este código:

index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Website</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Welcome to My Restaurant</h1>
  <button id="greetBtn">Click Me</button>

  <script src="script.js"></script>
</body>
</html>

style.css

body {
  font-family: sans-serif;
  text-align: center;
  margin-top: 50px;
}

button {
  padding: 10px 20px;
  background: #222;
  color: #fff;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

script.js

document.getElementById("greetBtn").addEventListener("click", function () {
  alert("Welcome to the coding kitchen!");
});

🚀 Cómo Ejecutarlo

  • Abrí la carpeta en VS Code
  • Click derecho en index.html → “Open with Live Server”
  • O simplemente abrilo en tu navegador

🧠 Primer Commit con Git

git init
git add .
git commit -m "My first website"

🔁 Luego subilo a GitHub:

git remote add origin https://github.com/your-username/my-first-website.git
git branch -M main
git push -u origin main
