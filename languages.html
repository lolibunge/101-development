Lenguajes y Tecnologías 🍜

Así como en la cocina existen distintas técnicas y estilos (italiana, japonesa, etc), en desarrollo hay distintos lenguajes y tecnologías.

🥇 ¿Por qué aparecen nuevos lenguajes?

  • Para resolver problemas de manera más eficiente
  • Para hacer el código más legible y fácil de mantener
  • Porque cambian los dispositivos y los hábitos de uso (ej. móviles)

Ejemplos con sabor 🍝

HTML, CSS, JavaScript = La base del plato

Son como el arroz, la pasta o el pan: están en casi todos los platos. Construyen la web visual.

React = Un chef con robots

Automatiza tareas repetitivas y mejora la velocidad de preparación visual. Muy popular en grandes cocinas.

Python = Recetas simples y poderosas

Fácil de leer, versátil y usado en todo: desde chatbots hasta análisis de datos. Ideal para chefs que quieren resultados sin complicarse.

Node.js = Cocina sin moverse del salón

Permite usar JavaScript en el backend. Es como si el mesero también pudiera cocinar.

SQL y MongoDB = Diferentes formas de guardar ingredientes

SQL es como una bodega ordenada por estanterías. MongoDB es como cajas sueltas con etiquetas flexibles.
