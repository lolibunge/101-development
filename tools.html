Herramientas en la Cocina del Código 🔧

Así como un buen restaurante usa utensilios y procesos para ser más eficiente, los desarrolladores también usan herramientas que mejoran el flujo de trabajo.

🔨 Frameworks

Son como plantillas de cocina: ya vienen con todo armado para que prepares un plato sin empezar de cero. Ej: React, Vue, Django.

🎨 Polaris

Es un sistema de diseño usado por Shopify. Es como tener platos, cubiertos y mantelería estandarizada para que todo se vea profesional y consistente.

⚙️ Git y GitHub

Git es como un libro de recetas con historial. GitHub es donde los chefs colaboran, comparten, revisan y mejoran las recetas juntos.

📦 Package Managers (npm, yarn, pip)

Herramientas para instalar ingredientes (librerías) fácilmente. Son como un delivery rápido de cosas que necesitás para cocinar.

🧪 Testing y QA

Como probar un plato antes de servirlo. Garantizan que no haya errores ni sabores extraños.

🚀 Deploy Tools

Son los servicios que llevan tu comida (sitio web) desde la cocina al cliente. Ej: Vercel, Netlify, Heroku.
